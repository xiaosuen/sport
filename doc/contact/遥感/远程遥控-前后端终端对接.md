## 1. `puppy_joy_teleop` 节点接口

### 1.1 订阅

| 话题 | 类型 | 说明 |
|------|------|------|
| `joy_topic` 默认 `/joy` | `sensor_msgs/Joy` | 手柄源；无包或无连接时发停。 |

### 1.2 发布（由 `output_mode` 与高度/俯仰开关决定）

| 话题 | 类型 | 条件 |
|------|------|------|
| `velocity_move_topic` 默认 `/puppy_control/velocity_move` | `puppy_control_msgs/Velocity` | `output_mode`=`velocity_move`（或未知时回退为该模式） |
| `cmd_vel_topic` 默认 `/cmd_vel_nav` | `geometry_msgs/Twist` | `output_mode`=`twist_nav` |
| `pose_topic` 默认 `/puppy_control/pose` | `puppy_control_msgs/Pose` | `enable_height_control` 或 `enable_pitch_control` 为真时创建发布者 |

**定时**：`create_timer(1/publish_rate)` 周期内读最新 `/joy` 并发布；`publish_rate` 默认 **30.0** Hz。  
**无 Joy / 超时**：`stale_timeout_sec`>0 且超时时，或从未收到 joy，调用 `_publish_stop()`（`Velocity` 全 0 或空 `Twist`）。

### 1.3 `output_mode` 与摇杆到消息的映射

| 模式 | 轴与默认下标 | 输出量 |
|------|--------------|--------|
| `velocity_move` | `axis_linear` 默认 **1**（前负后正经 `invert_linear`）、`axis_angular` 默认 **0**；均经 `deadzone` | `Velocity.x`（cm/s）=`lin_axis * velocity_move_max_cm_s`，再夹到 **\|x\|≤35**（`_VMOVE_MAX_CM_S`）。`Velocity.y` **恒 0**。**`yaw_rate`**= `ang_axis * scale_angular`，再夹到 **\|yaw\|≤50.9°**（`_VMOVE_MAX_YAW_RAD`）。 |
| `twist_nav` | 同上两轴 | `Twist.linear.x`=`lin_axis*scale_linear` 再夹 **±0.35**（`_PUPPY_NAV_MAX_LINEAR_X`）；`linear.y/linear.z/angular.x/angular.y`=0；**`angular.z`**=`ang_axis*scale_angular` 经 `max_angular` 与 **±50.9°**（`_PUPPY_NAV_MAX_YAW_RAD`）双夹。 |

**使能**：`require_enable_button` 默认 false；为 true 时 `enable_button`（默认 **4**）未按下则 `_publish_stop()`。注释：**高度/俯仰与使能解耦**——未按使能时仍先执行 `_maybe_publish_pose`。

**Pose**（`enable_height_control` 或 `enable_pitch_control`）：  
- **高度**：`axis_height`（默认 **3**）经死区、与 `height_axis_scale` 等积分离散积分 `_height_state`，范围 **`height_min`～`height_max`**；若 `height_only_when_linear_idle` 为真，仅当左摇杆**线速度轴**在死区内才调高度。  
- **俯仰**：L1 `button_pitch_up`（默认 **6**）持续按住按 `pitch_rate_rad_per_s` 增；L2 轴 `axis_pitch_down`（默认 **5**）经 `l2_axis_rest_value` / `l2_axis_pull_min` 归一化拉量，按 `pitch_down_rate_rad_per_s` 减；`pitch` 限 **±31°**；若 `pitch_only_when_linear_idle` 为真，仅线速度死区内可调。  
- 发布时 **`yaw` 恒 0.0**；`roll`=`pose_roll`，`pitch`=`_pitch_state`，`height`=`_height_state`，`x_shift/stance_x/stance_y/run_time` 见参数表。

### 1.4 节点参数（`declare_parameter` 默认值）

| 参数 | 默认 | 作用 |
|------|------|------|
| `joy_topic` | `/joy` | 订阅名 |
| `output_mode` | `velocity_move` | `velocity_move`∣`twist_nav`；其它字串回退 `velocity_move` |
| `cmd_vel_topic` | `/cmd_vel_nav` | `twist_nav` 时发布 |
| `velocity_move_topic` | `/puppy_control/velocity_move` | `velocity_move` 时发布 |
| `publish_rate` | `30.0` | 定时器 Hz |
| `axis_linear` | `1` | 前后 |
| `axis_angular` | `0` | 转向（非横移） |
| `invert_linear` | `false` | 前后反向 |
| `invert_angular` | `false` | 转向反向 |
| `scale_linear` | `0.35` | 用于 `twist_nav` 的 `linear.x` 缩放前 |
| `scale_angular` | `0.85` | 两模式转向缩放 |
| `max_linear` | `0.35` | `twist_nav` 中 `lin_axis*scale_linear` 初夹 |
| `max_angular` | `0.85` | `twist` 的 `angular.z` 初夹（再经 50.9° 硬限） |
| `velocity_move_max_cm_s` | `28.0` | 与 `lin_axis` 相乘得 cm/s 再经 35 硬限 |
| `deadzone` | `0.12` | 左摇杆两轴死区 |
| `require_enable_button` | `false` | 是否需按住使能键才发速 |
| `enable_button` | `4` | 使能键下标 |
| `stale_timeout_sec` | `0.0` | 0=关；>0 无新 joy 则停 |
| `debug_log_throttle_sec` | `0.0` | 调试日志节流域 |
| `enable_height_control` | `true` | 是否发 Pose 调高度 |
| `pose_topic` | `/puppy_control/pose` | |
| `axis_height` | `3` | 与 `axis_linear`/`angular` 同下标时关闭高度并报错 |
| `height_deadzone` | `0.12` | |
| `height_only_when_linear_idle` | `true` | 仅线速死区内调高度 |
| `height_axis_scale` | `-1.0` | 高度轴方向 |
| `height_rate_cm_per_s` | `5.0` | 高度积分率 |
| `height_min` / `height_max` / `height_initial` | `-15` / `-5` / `-10` | 高度界与初值 |
| `pose_roll` / `pose_pitch` / `pose_yaw` | `0` / `0` / `0` | 初值；发布时 yaw 仍写 **0.0** |
| `pose_x_shift` / `pose_stance_x` / `pose_stance_y` / `pose_run_time` | `-0.5` / `0` / `0` / `0` | 发布到 Pose |
| `enable_pitch_control` | `true` | 俯仰 |
| `button_pitch_up` | `6` | L1 抬头 |
| `axis_pitch_down` | `5` | L2 低头量 |
| `pitch_rate_rad_per_s` / `pitch_down_rate_rad_per_s` | `0.45` / `0.45` | 抬头/低头速率 |
| `l2_axis_rest_value` / `l2_axis_pull_min` / `l2_pull_deadzone` | `1.0` / `-1.0` / `0.03` | L2 拉量归一化 |
| `pitch_only_when_linear_idle` | `true` | 仅线速死区内调 pitch |

**代码硬常量**（无参数名）：`Velocity` 夹 **\|x\|≤35 cm/s**、\|yaw\|**≤50.9°**；`Twist` 线 x **±0.35 m/s**、角 z 最终 **±50.9°**；俯仰 **±31°**。

## 2. 远程 JSON 与上表对应（MQTT 体同构）

| 控制意图 | `joy_teleop` 侧 | 远程 JSON 侧（与 [远程遥控器.md](./远程遥控器.md) 一致） |
|------------|----------------|--------------------------------------------------------|
| 前/后 | `axis_linear` → `Velocity.x` 或 `Twist.linear.x` | `velocity.x` 或 `twist.linear.x`（单位见模式） |
| 左/右转 | `axis_angular` → `yaw_rate` 或 `angular.z` | `velocity.yaw_rate` 或 `twist.angular.z`；**无** `Velocity.y` 侧移 |
| 高度/俯仰 | 右摇杆、L1/L2 → `Pose` | `pose.height` / `pose.pitch` 等，网桥发 `/puppy_control/pose` |
| 停速 | 使能/无 joy/超时 → 零 `Velocity` 或 `Twist` | `stop` / `enabled` / 零 `velocity` |

`mode`=`velocity_move` 对应 `Velocity`+可选 `pose`；`mode`=`twist_nav` 对应 `Twist`+可选 `pose`。

根级与子对象字段、HTTP/MQTT 路径、响应与终端职责：**仍按 [远程遥控器.md](./远程遥控器.md) 与下表。**

| 节 | 内容 |
|----|------|
| 根级 `seq` `mode` `enabled` `velocity` `twist` `pose` `stop` | 同远程遥控器.md §3 |
| `Velocity` / `Pose` / `Twist` 子字段与单位 | 同远程遥控器.md §3 |
| 后端发 MQTT | `puppy/control/{device_id}/teleop` QoS1，体同 HTTP 请求体 |
| HTTP 响应、终端网桥限幅/超时/互锁 | 同远程遥控器.md §3 响应、§5 |

| 端 | 职责 |
|----|------|
| 前端 | 组 JSON 与 §1 映射一致；HTTPS/WSS+JWT；`seq` 递增；不直连 MQTT。 |
| 后端 | 验权后 MQTT 下发明文 JSON。 |
| 终端 | 订阅 → 发 `/puppy_control/velocity_move`、可选 `/puppy_control/pose`、可 `/cmd_vel_nav`；与 `joy_teleop` 同话题互锁见远程遥控器.md §5。 |
